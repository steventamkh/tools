How it works:
  1. Input: Student 1 pages 1…P, then Student 2 pages 1…P, and so on.
  2. Output: Page 1 of every student, then Page 2 of every student, and so on.
  3. The .zip option gives a separate file for each page number (Page 01, Page 02 …), each with all students in class-number order. This is handy when different teachers mark different questions.
  4. After marking, use the Marked Paper Returner to put the pages back into student order.
