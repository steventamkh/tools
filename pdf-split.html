PDF Splitter

Cut a PDF into equal chunks (e.g. every 4 pages) and name the files 01_xxx, 02_xxx… or xxx_01, xxx_02…

🔒 Runs entirely in your browser. Files are never uploaded.

1Choose a PDF

Click to choose or drag the PDF here

2How to split

Show pages, coloured by output file

3File names

Leave the name empty to get just 01.pdf, 02.pdf…

4Download

Notes:
  1. Pages are copied as they are, so text stays selectable and quality is unchanged.
  2. If the pages don't divide evenly, the last file is shorter. The tool warns you when this happens — handy for checking a scan has no missing pages.
  3. Use the Download button beside each file to save just that one.
  4. Password-protected PDFs need the password removed first.
