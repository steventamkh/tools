How it works
  • The scan images are not re-compressed: each A4 page shows one half of the original scan, so quality is unchanged and the file size stays about the same.
  • Left page first: normal book spreads (page 1 | page 2). Right page first: books read right to left, e.g. vertical Chinese text.
  • Booklet (unstapled): a stapled booklet taken apart and scanned sheet by sheet, front then back (the first scan shows the last page next to page 1).
  • Rotated scans are handled; the preview shows the page the right way up, as it will be cut.
